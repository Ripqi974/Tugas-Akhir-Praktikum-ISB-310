# Sistem Manajemen Penjualan Mobil Toyota

# Deskripsi
Sistem Manajemen Penjualan Mobil Toyota adalah website sistem manajemen berbasis web yang digunakan untuk mengelola data mobil Toyota, stok kendaraan, dan informasi penjualan.

# Fitur
- Navbar responsif
- Hero Section
- Dashboard Statistik (Total Mobil, Terjual, Stok)
- Daftar Mobil dalam bentuk card
- Form Tambah Data Mobil
- Desain responsif (Mobile Friendly)
